Serviço / Criação e desenvolvimento de sites

Criação de sites e desenvolvimento web em Miami

Todo site que o estúdio entrega é escrito à mão, em HTML, CSS e JavaScript. Sem construtor de páginas, sem tema comprado, sem pilha de plugins para manter. Isso não é nostalgia. É o único jeito de controlar quanto a página pesa, com que velocidade ela aparece e o que um buscador consegue ler.

O que o código escrito à mão realmente compra

Contra construtores e temas

Uma página de Wix ou Squarespace entrega um framework, um tema e o código de todos os recursos que você não usa. Um site em WordPress acrescenta um plugin para cada coisa que o tema esqueceu, e cada plugin traz a própria folha de estilo, o próprio script e o próprio risco de atualização. Você paga por isso em tempo de carregamento a cada visita, e em manutenção todo mês.

Uma página escrita à mão entrega só o que está nela. A página inicial deste site tem cerca de 250KB antes das imagens, e cada byte está fazendo alguma coisa. É essa margem que paga o vídeo de abertura, a fotografia em qualidade plena e o movimento, sem que a página pareça lenta.

A outra metade é controle. Dados estruturados, hierarquia de títulos, formatos de imagem e caminhos de rastreamento aqui são decisões, não opções enterradas num tema que não é seu.

O que um projeto inclui

Seis partes, um par de mãos

O estúdio não passa o projeto de um designer para um desenvolvedor e daí para um redator, que é exatamente onde a maioria dos trabalhos de agência perde a forma. A mesma pessoa desenha, escreve e constrói.

01 Direção de arte Como o site se parece e por quê, decidido antes de uma linha ser construída.
02 Design Tipografia, cor, espaçamento e movimento, desenhados sobre conteúdo real e não sobre texto de preenchimento.
03 Texto As palavras da página, escritas para serem lidas e para serem encontradas.
04 Desenvolvimento front-end HTML, CSS e JavaScript escritos à mão. Responsivo, acessível, testado em aparelhos de verdade.
05 Base para busca Marcação semântica, dados estruturados, metadados, sitemap e mídia comprimida.
06 Lançamento e entrega Publicação, análise de dados e uma passagem completa para que você consiga tocar o site sozinho.

Feito para como as pessoas realmente chegam

Celular, multilíngue, com agendamento

A maior parte do tráfego local é um celular, segurado com uma mão só, numa conexão pior que a sua. Tudo aqui é desenhado primeiro nesse tamanho e alargado depois, nunca o contrário.

Quando o público não é monolíngue, o site é construído em mais de um idioma a partir da mesma fonte e declarado ao Google com hreflang, para que uma busca em português ou espanhol caia numa página escrita naquele idioma. A Blend Hair Boutique funciona assim, em inglês, português e espanhol. Este site também.

E quando o negócio recebe agendamentos ou pedidos, o sistema de reservas é integrado, não pendurado num link de última hora, porque um site que termina num número de telefone perde quem não vai ligar.

Provas

Quatro projetos, quatro problemas diferentes

Os projetos são o argumento. Cada um diz o que existia antes, o que foi construído e para que foi construído.

Site trilíngue Blend Hair Boutique Oito páginas de serviço em três idiomas, todas terminando na mesma tela de agendamento. Busca local Renata Estrella Um site, um e-book vendido nele e um perfil no Google com 27 avaliações cinco estrelas. Identidade e site Bordados com Amor Um logotipo desenhado como bordado e um site em português em três capítulos. Site de portfólio Rafa Diniz O site de um fotógrafo onde o trabalho carrega antes de qualquer outra coisa.

Para quem isso é

E para quem não é

Serve para um negócio que vende algo específico a um público definível e que já foi mal servido por um template: um salão, um ateliê, um consultório, um artesão, um serviço local que compete por qualidade e não por preço.

Não serve para um projeto que precisa de cinquenta páginas no mês que vem, para um marketplace, nem para uma equipe que quer mexer no layout toda semana. O estúdio pega um projeto de cada vez, que é a razão de o trabalho ser o que é e também a razão de não ser a resposta certa para todo mundo.
